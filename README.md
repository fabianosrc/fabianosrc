## English

**IT Support · Windows troubleshooting · PowerShell automation**

I work in IT support, troubleshooting Windows and business applications. When the same issue keeps coming back, I look for a way to turn the fix into a repeatable process. PowerShell is my go-to tool for that, and I use Pester to turn bug reports into regression tests.

### Selected projects

- **[RDPControl](https://github.com/fabianosrc/RDPControl)** — PowerShell module for managing Remote Desktop on Windows. It brings together service and port configuration, user access, session management, and audit logs.
- **[PipeDFe](https://github.com/fabianosrc/PipeDFe)** — PowerShell module designed to ingest, process, and distribute Brazilian electronic fiscal documents (DF-e) through a pipeline.
- **[TermsrvPatcher](https://github.com/fabianosrc/TermsrvPatcher)** — My earlier Windows Remote Desktop project and the predecessor to RDPControl. Kept available as a legacy project.

## Português

**Suporte de TI · Diagnóstico no Windows · Automação com PowerShell**

Trabalho com suporte de TI, resolvendo problemas no Windows e em sistemas usados no dia a dia das empresas. Quando um chamado começa a se repetir, procuro transformar a solução em uma rotina que dá para executar de novo sem depender da memória. Uso PowerShell para automatizar essas tarefas e Pester para transformar relatos de bugs em testes de regressão.

### Projetos em destaque

- **[RDPControl](https://github.com/fabianosrc/RDPControl)** — Módulo PowerShell para administrar a Área de Trabalho Remota no Windows. Reúne configuração do serviço e da porta, controle de acesso, gerenciamento de sessões e registros de auditoria.
- **[PipeDFe](https://github.com/fabianosrc/PipeDFe)** — Módulo PowerShell pensado para receber, processar e distribuir documentos fiscais eletrônicos brasileiros (DF-e) em um fluxo por etapas.
- **[TermsrvPatcher](https://github.com/fabianosrc/TermsrvPatcher)** — Meu projeto anterior para Área de Trabalho Remota no Windows. Deu origem ao RDPControl e continua disponível como projeto legado.
